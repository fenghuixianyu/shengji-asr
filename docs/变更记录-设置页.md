# 变更记录 · 设置页（语言 / 精度收进右上角齿轮）

> 记录一次 **UI 调整**：把主界面内联的「识别语言」选择器收进独立的**设置页**，
> 主界面恢复成原来的样子，只在右上角新增一个齿轮入口。
> 本文含 用户反馈 → 方案 → 代码改动 → 上机验证 → 还原 的完整过程。

---

## 一、用户反馈（原始诉求）

上一轮（[`变更记录-语言模式切换.md`](变更记录-语言模式切换.md)）把「识别语言」选择器
**内联**插在主界面的精度档位区下面，主界面因此多出一整块。用户反馈：

> 「其实原来的那个界面我挺喜欢的。要不就在原来的界面右上角加一个设置图标，
> 点进去可以进行设置，比如切换识别语言和精度，然后保持原来的界面不变」

即：**主界面回到原样**，语言 / 精度这类「设置项」挪到二级页，用右上角齿轮进入。

---

## 二、方案

| 项 | 做法 |
|---|---|
| 主界面 | 删除内联的 `LanguageSelector`；`TopAppBar` 右上角加一个齿轮 `IconButton` |
| 主界面内容 | 保持原样：标题 + 精度档位区 + 双 Tab（导入文件 / 实时录音）+ 结果面板 |
| 设置页 | 新增 `SettingsScreen`：独立 `Scaffold` + `TopAppBar`（标题「设置」+ 左侧返回箭头），内容为「识别语言」选择器 + 「识别精度」选择器 + 说明文字 |
| 状态 | `showSettings` 用 `remember { mutableStateOf(false) }`，纯本地 UI 状态，不进 ViewModel、不持久化 |
| 返回 | 设置页返回箭头 + 系统返回键（`BackHandler`）都能回到主界面 |

> 之所以不把 `showSettings` 放进 `AsrUiState`：它是纯导航状态，与识别状态无关，
> 放在 Composable 本地即可，也不影响 ViewModel 的单元测试面。

---

## 三、实际修改（改动文件：1 个）

**`app/src/main/java/com/shengji/asr/ui/AsrApp.kt`**

1. **新增 import**：
   `androidx.activity.compose.BackHandler`、
   `androidx.compose.foundation.rememberScrollState`、
   `androidx.compose.foundation.verticalScroll`、
   `androidx.compose.material.icons.rounded.ArrowBack`、
   `androidx.compose.material.icons.rounded.Settings`。
2. **`AsrApp` 内新增 `showSettings`**，并在 `Scaffold` 之前提前分流：

   ```kotlin
   var showSettings by remember { mutableStateOf(false) }

   if (showSettings) {
       BackHandler { showSettings = false }
       SettingsScreen(
           state = state,
           onSelectModel = { vm.selectModel(it) },
           onSelectLanguage = { vm.selectLanguage(it) },
           onBack = { showSettings = false },
       )
       return
   }
   ```

3. **`TopAppBar` 加 `actions`**：右上角齿轮，`contentDescription = "设置"`。
4. **主界面删除** `LanguageSelector(...)` 调用（其余布局一行未动）。
5. **新增 `private fun SettingsScreen(...)`**：自带 Scaffold / TopAppBar，
   内容 `Column(...verticalScroll(rememberScrollState()))`，依次放
   `LanguageSelector` → `ModelSelector` →（切换中时）`LoadingBanner` → 说明文字。
6. `LanguageSelector` 与 `ModelSelector` 两个 Composable **原样保留**，
   只是调用点从主界面换成了设置页。

> **未改动**：模型文件、引擎（`AsrEngine.kt`）、ViewModel、导出逻辑（TXT / SRT）。

## 五、如何还原

### 还原到「语言选择器内联在主界面」（本次改动之前的状态）

1. `ui/AsrApp.kt`：
   - 删除 `showSettings` 与 `if (showSettings) { ... return }` 分支；
   - 删除 `TopAppBar` 的 `actions = { ... }`（齿轮）；
   - 删除 `SettingsScreen(...)` 整个函数；
   - 把 `LanguageSelector(state = state, onSelect = { vm.selectLanguage(it) })`
     放回主界面 `ModelSelector` 下方；
   - 删除本次新增的 5 个 import（`BackHandler` / `rememberScrollState` /
     `verticalScroll` / `ArrowBack` / `Settings`）。
2. 重新构建：`./gradlew assembleStdDebug assembleFullDebug`。

### 只想改入口位置

- 想把设置项再挪到别处，只需搬动 `SettingsScreen` 里那两个选择器调用；
  `LanguageSelector` / `ModelSelector` 本身无需改动。

> 改动**可逆且隔离**：只涉及 `ui/AsrApp.kt` 一个文件，不触碰模型、引擎与导出逻辑。
