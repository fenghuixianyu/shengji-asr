### 1. 导入音频 / 视频自动转文字

官方版只能实时录音。新增：

- 文件选择器（`ActivityResultContracts.OpenDocument`），支持
  `mp3 / wav / m4a / aac / flac / ogg / opus / amr / wma` 与
  `mp4 / mkv / mov / avi / webm / 3gp`。
- `AudioDecoder.kt`：`MediaExtractor` 抽音轨 → `MediaCodec` 解码 →
  重采样 16 kHz 单声道 PCM。
- `SpeechSegmenter.kt`：Silero VAD 自动切段。
- 识别结果带时间轴，可导出。

**还原**：移除「导入文件」Tab 与相关按钮，不再调用 `AudioDecoder` / `SpeechSegmenter`，
即回到「只能录音」的官方行为。

### 2. 界面布局重做

- 顶部标题 + 精度档位区 + 双 Tab（导入文件 / 实时录音）+ 结果面板。
- 结果区标题与操作按钮分两行，一行放得下 5 个按钮。
- 全部用 Jetpack Compose 实现（`ui/AsrApp.kt`）。

**还原**：用官方 `MainActivity` 布局替换 `AsrApp.kt`。

### 3. 识别精度档位

「精度档」是**换模型**实现的（不是同一模型的量化精度差异）：

| 档位 | 模型 | 体积 | 速度 | 特点 |
|---|---|---|---|---|
| 标准（默认，性价比最高） | SenseVoice 2024-07-17（int8） | ~239 MB | 最快 | 中/英/日/韩/粤，自带标点与数字规整 |
| 高精度 | FunASR-Nano（int8） | ~993 MB | 约 4 倍慢 | 中文更准，尤其人名 / 古文 / 专有名词 |

- `AsrModels.kt` 按 `BuildConfig.FULL_BUILD` 决定可选档位。
- 构建 flavor：`std`（只内置标准档）/ `full`（标准档 + 高精度档）。
- **经验结论**：日常场景两档差距很小，标准档就够；高精度档只在人名 / 古文 /
  专有名词上更准。实测 16 段官方中文音频：高精度档 8 段更准、1~2 段反而更差、
  其余打平，耗时约 4.2 倍。所以默认给标准档。

**还原**：删除档位 UI 与 `AsrModels` 的多档逻辑，只保留 SenseVoice。

### 4. 导出（含带时间戳 TXT / SRT）

结果面板 5 个按钮：复制 / 导出纯文本 TXT / 导出带时间戳 TXT / 导出 SRT / 清空。
`Transcript.kt` 负责格式化；带时间戳 TXT 每行 `[起始时间 - 结束时间] 文本`
（2026-10-14 由「仅起始时间」`[时:分:秒]` 改为「起止时间」，与 SRT 语义对齐）。

**还原**：只保留官方原始的「复制」即可。

### 5. 命名与图标

- 应用名：`声迹`（full 档 `声迹 Pro`）。
- 包名：`com.shengji.asr`（full 档 `com.shengji.asr.full`，两者可共存）。
- 自适应图标：满幅渐变背景层 + 声波字形前景层 + 单色层；

**还原**：改回官方包名 / 名称，换回官方图标。

### 6. 中文识别增强

- **问题**：中文短句被识别成拼音 / 日文（「你好」→ `Lihao.`），且不稳定。
- **根因**：sherpa-onnx 内置 `language = null`（自动语种检测），短音频易误判语种。
- **改法**：`AsrEngine.kt` 里强制 `language = "zh"` 并开启 ITN（唯一改动文件）。

**还原**：删除 `tuneForChinese(...)` 调用与方法，回到自动检测 + ITN 关闭。

> [`变更记录-中文识别增强.md`](变更记录-中文识别增强.md)。

### 7. 应用内语言模式切换

原先「中文优先」是写死的（改造 6）。本次把它升级为**应用内可切换的三档语言模式**：

| 模式 | `language` | 特点 |
|---|---|---|
| 中文优先（默认） | `"zh"` | 中文最稳，短句不出拼音；英文偶被拉成中文 |
| 英文优先 | `"en"` | 英文最稳；中文明显退化 |
| 多语种自动 | `""` | 恢复模型原生 auto 判别，中 / 英 / 日 / 韩 / 粤 |

- 语种是**构造识别器时**写进 native 配置的，所以切换语言模式会**重建识别器**
  （标准档瞬间完成；高精度档要重新加载大模型，会明显卡一下）。
- 涉及文件：`AsrEngine.kt`（`load(modelType, languageCode)` + `tuneForLanguage`）、
  `AsrModels.kt`（`LanguageMode` 与三档实例）、`AsrViewModel.kt`（
  `selectLanguage` / `reloadRecognizer`）、`ui/AsrApp.kt`（`LanguageSelector`）。
- **关键坑**：FunASR-Nano 的 `language` 是 prompt 自由文本，不是语言码，
  必须映射成中文词（`zh→中文`、`en→英文`、`""→""`）；SenseVoice 侧才是标准语言码。

**还原**：删除 `LanguageSelector` 与 `LanguageMode`，把 `load(modelType, languageCode)`
的第二参数去掉、`tuneForLanguage` 换回固定 `"zh"` 的 `tuneForChinese`，
即回到「写死中文优先」。详见 [`变更记录-语言模式切换.md`](变更记录-语言模式切换.md)。
